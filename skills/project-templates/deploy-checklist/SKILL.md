## Before every deploy
1. The working branch is clean and pushed. CI is green.
2. Required environment variables exist in the host for the target environment. Names are in `.env.example`.
3. Database changes are applied to the target database with the migration tool, never by hand, and a backup was taken first for production.
4. Run the smoke check: public URL returns 200 and shows the expected version.

## Never
- Point a local or preview build at the production database.
- Print, log, or commit secrets. Browser code may only use public keys.
- Deploy or run migrations against production without asking the user first.

## After deploy
Check the error dashboard and uptime monitor for ten minutes. If something is wrong, roll back first, investigate second.
