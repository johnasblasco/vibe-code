# Generation Data

Output definition: id, source, path, format, when, optional always. IDs and case-insensitive
destination paths are unique. Paths are contained portable components, not answer-derived.
Git internals, traversal, device names, alternate streams, trailing dots, and links reject.

Pin: id, exact value, official source, verifiedOn, mode live/pack, optional release tag.
Pack fallback age must be nonnegative and within max_age_days; malformed responses do not
fall back. Action/hook hashes have exactly 40 lowercase hexadecimal characters. Runtime and
image versions are numeric stable releases. Node stays on the pack's selected LTS major.

GenerationPlan: complete GeneratedFile[] and Pin[]. MissingAnswers carries only known question
IDs and a contact-needed flag. No partial plan is published when a binding is missing.
GeneratedFile: manifest ID, contained destination, complete rendered content.

Question answers retain the existing three states. Only current concrete answered values fill
bindings; deferred/not-applicable and unresolved recommendation sentinels cannot. A security
contact is separate generation input, validated as an email or credential-free HTTPS URL.

PublishError: completed relative paths, allowing honest partial-batch reporting. Owned temporary
files are cleaned up; published files and preexisting user files are never deleted on failure.
